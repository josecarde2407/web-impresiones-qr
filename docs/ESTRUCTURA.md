# Root Package.json - Información del Proyecto

Este archivo contiene información sobre el proyecto. La instalación y ejecución se realiza desde la carpeta `backend/`.

## Estructura

- **backend/** - Servidor Node.js/Express
- **frontend/** - Archivos estáticos (HTML, CSS, JS)

## Para iniciar el proyecto

```bash
cd backend
npm install
npm start
```

O para desarrollo:

```bash
cd backend
npm install
npm run dev
```

La aplicación estará disponible en `http://localhost:3000`
