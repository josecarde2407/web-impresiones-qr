# web-impresiones-qr

Aplicación web para generar códigos QR e imprimir en impresoras Zebra.

## ✨ Características

- ✅ Generación de códigos QR
- ✅ Impresión en impresoras Zebra ZPL
- ✅ Gestión de ubicaciones de almacén
- ✅ Importar/Exportar datos en Excel
- ✅ Panel de administración
- ✅ API REST completa

## 📦 Estructura Actualizada

El proyecto ha sido reorganizado en **backend** y **frontend** para una mejor separación de responsabilidades:

```
backend/    - Servidor Node.js + Express
frontend/   - Cliente HTML/CSS/JavaScript
```

Ver [ESTRUCTURA.md](./ESTRUCTURA.md) para detalles.

## 🚀 Instalación Rápida

```bash
cd backend
npm install
npm start
```

Visita `http://localhost:3000`
